# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。
## 1.预处理  
对整个程序进行初步加工，便于后续的开展。简单来说就像是做一道菜的最开始是洗菜，按要求去掉一些不要的东西（注释之类的），或者按要求加一些相关的东西（宏定义，#include的一些文件啊），方便之后的处理。  
## 2.编译  
对初步处理过后的源码进行词法分析，语法分析，语义分析，判断程序是否有bug以及将整个程序加工成汇编语言，更贴近机器的语言。更贴近机器的意思是，我们原本的程序只是一个个变量和函数，但经过编译之后变成了一个个变量和寄存器，里面的对象变成了机器里的部件。

## 3.汇编 
将编译阶段产生的汇编代码，进一步转换成机器能够识别的和执行的机器指令，也就是二进制代码并生成对应的文件。

## 4.链接  
因为有多个文件之间相关的引用和库的调用（可能），所以会产生多个文件，最后这步就是为了连接不同文件，统合成一个程序
